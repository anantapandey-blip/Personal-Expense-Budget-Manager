# Personal-Expense-Budget-Manager
A Python based expense management application built using Object-Oriented Programming (OOP).


## Features

* Add new expenses with amount, category, and description
* View all recorded expenses
* Search expenses by amount, category, or description
* Calculate total monthly spending
* View category-wise spending
* Set and manage a monthly budget
* Check remaining budget
* Save expense data to a text file
* Delete an expense
* Clear saved expense history
* Exit the application

##  Concepts Used

This project demonstrates:

* **Object-Oriented Programming (OOP)**
* Classes and Objects
* Constructors and Instance Attributes
* Instance Methods
* Lists
* Dictionaries
* Loops and Conditional Statements
* User Input
* String Methods
* File Handling
* `with open()` and `"w"` file mode

##  Data Storage

Expense information can be saved in a text file named:

```text
expenses.txt
```

The project uses Python's file handling to create and save expense data.

##  How to Run

Make sure Python is installed, then run:

```bash
python "Personal_Expense_&_Budget Manager.py"
```

Follow the menu displayed in the terminal to manage your expenses.
